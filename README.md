# Aquamirae & Nouveau

独立的海灵物语与 Ars Nouveau 联动附属，使用 Ars Conflux 中立 API。
显示名称：**Aquamirae & Nouveau**；Mod ID：`aquamirae_nouveau`；作者 EndXiom；附属代码许可 MIT。
当前版本 **0.1.0-dev.9**。原模组由 Obscuria 开发；本项目不代表其官方，也不打包原模组代码或素材。

五个状态魔符、两个碎裂迸裂魔符和三项生物能力属于 **效果**；深渊碎晶、可怖环刃、迷宫玫瑰属于弹射物替换 **增强**，紧随弹射物形态书写。所有魔符默认等级统一为 Tier 1。原版 Ars 形态和增强的费用仍由 Ars 收取。
状态魔符每个成功触发单独支付上述载荷费用；每个书写增强额外支付 10 Mana。
原有四个状态魔符在原生效果未改变时不支付载荷费用。水母蜇刺按原生毒素助手接受施加计费；没有适用实体、友军、空蓝或载荷生成失败时不支付载荷费用。创造模式免载荷费。普通替换弹射物按成功生成计费，重复载体按有效命中计费。
形态与后续效果仍遵循原生 Ars 行为；不将选中的实体变成施法者、伤害所有者或付款者。

两个碎裂魔符每次成功触发追加一层，增强再加层数，受各自上限限制。
深海之怒和深海韧性默认一级，增强增加等级，同级重复触发只刷新持续时间，不累加层数。
延时为每个原生状态增加默认 200 tick（10 秒），原有状态总时长最多 72000 tick；咆哮与旋流另有 15／20 秒的默认上限。
深海属性的装备和伤害收益完全由原模组处理；它们不是固定的最终伤害或减伤百分比。
生命碎裂降低的是生命上限，原生移除与健康值处理保持不变；效果结束不会自动补血。

水母蜇刺调用原生 `AquamiraeHelper.doPoison`，保留伤害所有者归属，并附加水母接触攻击的失明和声音。增强提高中毒等级，最高 V；延时同时延长中毒和失明。保留深海水母、鮟鱇鱼的原生豁免，跳过友军、创造和旁观玩家。它以原生中毒效果造成后续伤害，没有额外直接伤害。

碎甲迸裂、碎命迸裂将原武器完整能力的满层额外伤害作为条件效果，直接调用本体阈值、数值和声音，不消耗碎裂层数。未满层、友军、空蓝、无敌帧拒绝或 Ars 伤害事件取消时不支付载荷费。伤害通过 Ars 的伤害效果 API，保留法术伤害加成、事件和实际伤害所有者；持有原生装备时仍走本体装备能力与减伤，最终伤害可能与基础值不同。两项不支持增强或延时。
例如重复命中 `弹射物 → 护甲碎裂 → 碎甲迸裂`，达到五层后开始产生迸裂伤害；生命碎裂与碎命迸裂同理，阈值十层。默认配置不要求手持来源武器，抄写时会消耗该武器。

可怖环刃和迷宫玫瑰继承原生实体，使用原生渲染器。普通弹射物保留穿透、回转和飞回所有者的运动；迷宫玫瑰保留原生 `Monster` 候选范围，不锁定友军。史莱姆不属于原生玫瑰追踪候选，但可以直接命中。两项武器仅支持加速，不通过增强改变原生伤害或状态。
每次原生伤害被接受后续接后续 Ars 效果；无敌帧拒绝伤害时不续接，也不重复付费。碰到方块保留原生处理，不触发 Ars 续接。普通回旋镖最多存活 120 tick；环绕等受控形态沿用 ArsTrajectory，上限 1200 tick，并停用原生运动和碰撞。原施法者失效、区块未加载、到期或空蓝导致执行会话取消时清理实体；重新载入缺失运行时上下文的载荷也会移除。

深渊碎晶通过 Conflux ProjectileForm 消耗原 Ars 弹射物生成，场上只有替换后的碎晶。主碎晶可直接碰撞普通生物；16 格追踪针对敌对生物和正在攻击所有者的生物，包含不继承 Monster 的史莱姆、岩浆怪。继续使用本体追踪运动、液体阻力、虚弱、分裂和 200 tick 生命周期。继承本体碎晶类并引用本体渲染器，不修改普通原生实体。
增强将原生尺寸每次加 0.2，尺寸上限 2，相应提高原生伤害，并改变其原生追踪建立速度；子碎晶仍固定尺寸 0.5。
主碎晶命中实体或方块时续接后续 Ars 魔符，保留目标、所有者、付款者与入射方向。分裂生成的三个子碎晶只保留本体伤害和虚弱，不续接 Ars 魔符、不再次扣费。
主碎晶、子碎晶和受控 Ars 载体均通过 Conflux `Allies.areAllies` 排除原施法者的友军，不锁定、不碰撞、不施加伤害或后续效果；受控重复形态也不因友军扣费。支持队伍、所有权及 Core 扩展提供者，中立生物仍可被直接命中。仅本附属产生的碎晶与载体启用筛选，普通海灵碎晶与普通 Ars 法术保持原样。
环绕及其他 Core 已登记的受控形态通过 ArsTrajectory 保留原轨迹和碰撞；替换实体停止原生移动/碰撞，客户端同步控制模式，避免两个驱动器。重复命中形态每次命中支付载荷费，保持完整、不分裂；单次命中形态在生成时支付一次。
Core ExecutionSession 负责所有者失效、空蓝、区块未加载、到期和取消清理。载荷不跨存档保存续接；失去运行时控制器或友军上下文的重新载入实体会移除。分裂子碎晶遵循本体生命周期，原施法者失效也会移除。
Forge 7.1.14 没有该实体，因此不注册深渊碎晶、配置或获取配方。

鳗鱼咆哮、船长旋流施加给自身或 Conflux 判断的友军；目标只负责执行位置，原施法者仍是付款者与友军判断来源。允许同时给多个友军建立控制源，每个成功授予分别收取初费和续费；同一个执行者上的同项增益不会叠加或再次收费。第一笔费用包含首秒，之后每秒预付续费；续费不足、施法者或执行者失效、关系变为非友军、换维度、区块卸载或净化时停止。重载不会恢复临时施法会话，孤立状态会在实体加入世界时清除。
咆哮持续影响执行者前方 90 度内、默认约 12.25 格以内且可见的敌人，刷新缓慢 II 和黑暗 10 秒，并增加冻结累积。扩散每次扩大范围 2 格，上限 32；延时增加持续时间。不向友军或创造／旁观玩家施加效果。
旋流默认查询执行者周围向各轴扩张 10 格的区域，使敌人趋向半径 5 格的旋转位置，正常到期的最后一帧向外推。强化每次将目标生命上限门槛提高 50，最高 1000；扩散每次扩大查询范围 2 格，上限 32；延时增加持续时间。保留视线与友军排除，不附送船长回血、浮空、破船者事件或视觉闪电。
吸血咬击直接作用于命中的敌方实体，无需持续增益。强化每次增加 2 点基础伤害，延时只延长中毒；伤害走 Ars 伤害事件与本体世界管线。按命中前后真实生命减少的两倍治疗实际伤害所有者，不把吸收护盾或过量伤害算进治疗。无敌帧拒绝、事件取消、友军和空蓝都不产生治疗或付款。
这三项是对生物独有动作的原创法术适配，原动作嵌于实体 tick／动画中，没有完整独立施法入口。复用原生毒素助手、状态、声音与旋流幽灵粒子；不生成隐形原生怪物，也不复制 Boss AI。咆哮前方群体选择、持续时间与增强是附属设计。客户端外观仍需人工验证。

例如：`弹射物 → 护甲碎裂 → 伤害`、`自身 → 深海之怒`、`弹射物 → 深渊碎晶 → 护甲碎裂`、`自身 → 环绕 → 深渊碎晶 → 伤害`、`弹射物 → 可怖环刃 → 水母蜇刺`、`弹射物 → 迷宫玫瑰 → 护甲碎裂`。旧版 `自身 → 深渊碎晶` 须重新编排。

图标和配方使用同一个明确来源物品；抄写会消耗该物品（包含原生武器）。图标只运行时引用本体贴图，未复制本体图片或实现。法术书名称和描述使用实际 Ars `glyph_name` / `glyph_desc` 键，两版中英资源由发行检查覆盖。

原生增益来源：鮟鱇鱼精华提供深海之怒 I / 3 分钟，精华串提供 III / 8 分钟；熟棘鱼提供深海之韧 II / 3 分钟，海鲜砂锅提供 III / 8 分钟，海炖菜提供 III / 5 分钟；波塞冬的早餐同时提供两项 IV / 10 分钟。两版发行 JAR 的食品注册一致。
深海之怒与深海之韧作用于本体深海属性和特殊战斗规则；默认涉及冰迷宫生物标签，不是对所有生物的通用力量或抗性。

`aquamirae_nouveau-server.toml` 可调整触发费用、增强附加费、状态时长、延时时长和冷却；本机 NeoForge 在实例 `config/`，Forge 在世界 `serverconfig/`。
`creatureActions` 可调整咬击基础伤害、咆哮和旋流每秒续费、单次时长上限、结束后的主动恢复期。增益状态图标通过原版状态图集引用同一来源物品纹理，没有复制图片。
冷却通过 Conflux 的主动施法 API 在确认释放时按施法者、按魔符记录；换工具不能绕过。
同次编排重复魔符只记录一次冷却，已有弹射物、环绕和其他后续触发继续执行；自动装置与被动 resolver 不作为新的主动施法。
两项持续控制成功命中时再延长主动冷却，避免飞行途中耗尽 CD；咆哮结束后至少保留 20 秒（包含 10 秒残留减益），旋流结束后至少保留 15 秒。多份会话取最晚结束时间，旧载体仍可独立授予并付款，不限制控制源数量。死亡重生保留本附属冷却。默认完整咆哮／旋流载荷费用为 128／264，单个自身编排总价为 138／274；延时后载荷费用为 248／424，多个友军按份相加。
创造模式默认绕过冷却，可通过 `creativeCooldown` 启用；`cooldowns.enabled` 全局关闭，某个 `cooldowns.seconds` 设为 0 仅关闭该魔符。
未命中也会记主动释放冷却；是否扣载荷费取决于后续效果是否成功触发。
默认咆哮前摇 13 tick（0.65 秒）、旋流 20 tick（1 秒），由 Core 统一准备；混合配方按 Core 的 MAXIMUM／SUM 聚合。顶部原版进度条显示剩余时间，换物品／死亡／换维度会取消，取消不付载荷或登记冷却。普通魔符保持瞬发，命中和续费不重复吟唱。`chanting.enabled` 独立关闭，两个时间均可配置；客户端实际进度条表现仍需人工验证。

Mana、吟唱和冷却的来源见 [dev.8 平衡审计](docs/balance-audit-dev8.md)，本版采用长冷却与费用调整；按用户新指示保留多个控制源，不采用审计中的数量限制。弹射物收益、计费与编排校验复核见 [dev.9 弹射物复核](docs/projectile-balance-dev9.md)。
旧配置不会随 JAR 自动覆盖。`python tools/update_balance_config.py 路径/aquamirae_nouveau-server.toml` 显示迁移计划；加 `--apply --backup 明确备份文件路径` 才写入。本工具只更新原 dev.8 默认值、补齐新设置，保留不同于旧默认的自定义值和其他配置项。

NeoForge 在根目录用 Java 21；Forge 在 `forge/` 用 Java 17，各自运行 `./gradlew.bat :runGameTestServer :jar :sourcesJar --offline --console=plain`。
Forge `jar` 会执行 `reobfJar`；只使用重混淆后的最终 JAR。两版可用 `-PconfluxCheckout=...` 指定独立 Core。
根目录 `python tools/verify_release.py` 验证 NeoForge 产物，加 `--forge` 验证 Forge 产物。
`tools/generate_resources.py` 维护共享的中英文本、NeoForge 配方和贴图引用；Forge 构建转换为 Ars 4 的配方格式。
