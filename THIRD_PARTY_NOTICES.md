# Third-party dependencies

Aquamirae & Nouveau is an independent integration by EndXiom, not endorsed by Obscuria or Ars Nouveau's authors.
The MIT license covers this addon's original code and JSON files only.

- Aquamirae and Fragmentum: Obscuria, Obscuria Modding License (OML). Official source: https://github.com/ObscuriaLithium/Aquamirae and https://github.com/ObscuriaLithium/fragmentum . Original, unmodified dependencies are installed separately. No upstream implementation, textures, models, sounds, or JARs are bundled. Item texture paths and registered effects/entities are referenced at runtime. OML 1.3 sections 1.1 and 1.4 permit compatibility layers and dependencies; this integration does not grant rights to republish upstream code or assets.
- Ars Nouveau: baileyholl and contributors, LGPL-3.0 family / GPL notices as declared in the installed distribution. https://github.com/baileyholl/Ars-Nouveau . API dependency only; not bundled or copied.
- Ars Conflux: EndXiom, MIT. Separate API dependency, not bundled.
- GeckoLib: authors listed in its original distribution, MIT. Separate dependency of the original mods.
- Curios and Patchouli: separately installed Ars dependencies; their licenses remain in their original distributions.

Local ignored libs/ and .upstream/ are development inputs, excluded from both binary and source release packages.
